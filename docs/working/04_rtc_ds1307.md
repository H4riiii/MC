# 4. Real-time clock (DS1307)

## What it does
The DS1307 keeps counting seconds from a 32.768 kHz crystal, with a coin-cell battery, so the time survives power-off. It has I2C address `0x68`.

## Registers (7 bytes, in BCD)
BCD means each decimal digit takes 4 bits: 42 is stored as `0x42`. `BCD_TO_DEC` / `DEC_TO_BCD` in `ds1307.h` convert.

| Reg | Holds | Notes |
|---|---|---|
| 0x00 | seconds | **bit 7 = Clock Halt**; if set, the clock is stopped |
| 0x01 | minutes | |
| 0x02 | hours | bit 6 = 12/24-hour mode, bit 5 = PM in 12-hour mode |
| 0x03 | day of week | 1 to 7 |
| 0x04 | date | |
| 0x05 | month | |
| 0x06 | year | two digits; the driver adds 2000 |
| 0x07 | control | square-wave output |

## Driver (`ds1307.c`)
- **`DS1307_Init`**
  - Checks the chip answers.
  - Reads the registers and clears the Clock Halt bit if set, keeping the time that was stored.
  - Forces 24-hour mode.
  - If the date or month is zero, writes 2 November 2026.
  - Turns off the square-wave output.
- **`DS1307_GetTime`** reads all 7 registers in one transfer, masks the flag bits, converts from BCD, and handles 12-hour mode if it is found.
- **`DS1307_SetTime`** writes all 7 registers with bit 7 of seconds at 0 (clock running) and 24-hour mode.

All transfers use a 10 ms timeout so a missing RTC cannot freeze the program.

## How `main.c` uses it
Every 500 ms the loop calls `DS1307_GetTime`:
- **Success:** if the seconds changed since last time, the new reading becomes the current time.
- **Seconds not changing for 1.5 s:** the RTC's oscillator looks stalled. The code calls `DS1307_Init` to restart it and advances the software time by one second.
- **Read failed:** the RTC is treated as missing (`!` shown in the header). A **software clock** takes over, adding one second for every 1000 ms measured with `HAL_GetTick`. It rolls over seconds, minutes, hours and increments the date at midnight; it does not handle month or year changes.

The date is used for two things: deciding whether an alarm already fired today, and detecting a day change for the history.
